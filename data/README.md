# Data

`DSL-StrongPasswordData.csv` is the CMU Keystroke Dynamics Benchmark Data Set (Killourhy and Maxion, DSN 2009): 51 subjects, 400 repetitions of the password `.tie5Roanl`, 31 timing features per repetition. Original source: https://www.cs.cmu.edu/~keystroke/. Cite the benchmark paper when using it.

The CSV file is not redistributed here. Download `DSL-StrongPasswordData.csv` from the source above and place it in this folder before running the scripts.
